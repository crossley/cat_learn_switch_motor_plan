# Category Learning During Task Switching (Switch Motor Plan 2)

This subdirectory contains the follow-up study (`switch_motor_plan_2`).

## Repository Structure

- `code/`: experiment and analysis scripts
- `images/`: cue images used by the task
- `data/`: participant data output directory (currently empty)
- `dbm_fits/`: decision-bound model output directory (currently empty)
- `figures/`: analysis figure output directory (currently empty)
- `consent/`: study consent materials (currently empty)

## Running

Scripts use relative paths (for example `../images` and `../data`), so run from `code/`:

```bash
cd switch_motor_plan_2/code
python run_exp.py
```
